# Starlog

Starlog is being redesigned as a daily workspace for curiosity, clear thinking, and reflection.

The planned first experience combines notes and questions, a useful daily brief, a customizable evening journal, and a searchable reading collection. It is web-first for laptop and phone.

Read [PLAN.md](PLAN.md) for the complete canonical vision, first iteration, future direction, and open decisions.

The fresh application has not been built. This repository still contains the previous implementation; its presence does not mean the new workflows are available. See [current state](docs/CURRENT_STATE.md).

Previous plans, interface concepts, setup guides, and implementation history are preserved in the [legacy archive](docs/archive/2026-10-03-legacy/README.md). Consult them only when intentionally working with the old application.
